# @eslint/jskit-native-win32-x64

The Windows x64 binary for
[`@eslint/jskit-native`](https://github.com/eslint/jsnext/tree/main/packages/jskit-native#readme).
Do not install this package directly; install `@eslint/jskit` (or
`@eslint/jskit-native`), which lists every platform package as an optional
dependency, and npm installs the one whose `os` and `cpu` fields match the
machine.
